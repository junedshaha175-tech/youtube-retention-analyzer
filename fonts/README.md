# Fonts

Used by the Auto Thumbnail Maker (`thumbnail.py`). All are licensed under the SIL Open Font License 1.1
(see `OFL.txt`, https://openfontlicense.org):

- `Anton-Regular.ttf` — Anton, The Anton Project Authors (https://github.com/googlefonts/AntonFont)
- `Bangers-Regular.ttf` — Bangers, Vernon Adams / Google Fonts
- `Poppins-Bold.ttf` — Poppins, Indian Type Foundry (https://github.com/itfoundry/poppins)

Hindi (Devanagari) titles use a system font (Nirmala UI on Windows, FreeSans via `packages.txt` on Streamlit Cloud).
